# Tadbirkor.uz — Android Studio Loyihasi

Ushbu loyiha Tadbirkor.uz platformasi uchun maxsus ishlab chiqilgan rasmiy Android ilovasidir.

## Xususiyatlar:
- **Server:** `https://teacher-startup-1.onrender.com`
- **Texnologiya:** Kotlin + Android WebView + Material3
- **Swipe-to-Refresh:** Sahifani pastga tortib yangilash
- **Oflayn rejim:** Internet uzilganda maxsus chiroyli ekran va "Qayta urinish" tugmasi
- **Rasm yuklash:** G'oyalar uchun rasm tanlash (File Chooser) to'liq ishlaydi
- **Tashqi havolalar:** Telegram (`tg://`), WhatsApp (`wa.me`) va telefon qo'ng'iroqlari alohida ilovalarda ochiladi
- **Orqaga tugmasi (Back navigation):** Brauzer tarixi bo'yicha orqaga qaytadi

## Qanday ishga tushiriladi (APK yaratish):
1. **Android Studio** dasturini oching.
2. **File -> Open** ni tanlang va mana shu `android` papkasini tanlang.
3. Android Studio Gradle kutubxonalarini avtomatik yuklab oladi (Sync).
4. APK chiqarish uchun:
   - Yuqori menyudan: **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** ni bosing.
   - 1 daqiqada `app-debug.apk` tayyor bo'ladi!
